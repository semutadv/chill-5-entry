One sentence, written for the make.fun bounty "One Line, One Chill" —
the scariest single sentence I could write. No monsters, no gore: a
woman, a mirror, and a reflection that has blinked a half-second late
for years. Tonight it stopped blinking first, which means it is no
longer following. It is leading.

## Running it

`node main.ts` clears the output directory's contents and writes the
sentence to `/output/entry.txt` as plain UTF-8 text.
